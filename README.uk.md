# NyxilumNode

*[English](README.md)*

Виконує програми, написані на мові **NyxilumLang** (`.nx` файли). Аналог
`node.js`, тільки для NyxilumLang: готовий бінарник, встановлення, менеджер
бібліотек — .NET встановлювати не треба.

Вихідний код самої мови — окремий репозиторій:
[github.com/Faneraiy14/NyxilumLang](https://github.com/Faneraiy14/NyxilumLang).

## Встановлення

.NET встановлювати не треба: усе потрібне вже всередині.

**Windows** — інсталятор, як у Node.js: скачай **`Nx-win-x64-setup.exe`** зі сторінки
[Releases](../../releases/latest) і натискай «Далі». Адмін не потрібен (ставиться для
поточного користувача). Буде ярлик **«Nx IDE»** на робочому столі й у меню «Пуск», команда
`nx` у терміналі, видалення — через «Програми». Якщо Windows покаже «Windows захистила ваш
ПК», то інсталятор просто не підписаний платним сертифікатом: «Докладніше» → «Виконати все одно».

**Ubuntu / Debian** — скачай **`Nx-linux-x64.deb`** і відкрий подвійним кліком («Встановити»),
або:

```bash
sudo apt install ./Nx-linux-x64.deb
```

**Будь-який Linux або macOS** — однією командою, без sudo (усе в `~/.nyx`, ярлик «Nx IDE»
у меню й на робочому столі):

```bash
curl -fsSL https://raw.githubusercontent.com/Faneraiy14/NyxilumNode/main/install.sh | bash
```

**macOS** — ще є пакет `Nx-osx-arm64.pkg` (Apple M1/M2/…) / `Nx-osx-x64.pkg` (Intel): він не
підписаний, тож відкривай правою кнопкою → «Відкрити».

**Вручну** — архів `.zip` / `.tar.gz` з тієї ж сторінки: розпакуй і запусти `install-nx.ps1`
(Windows) або `bash install-nx.sh` (Linux/Mac).

Перевірка (будь-яка платформа, у **новому** терміналі):

```bash
nx --version
```

**Оновлення:** `nx update-self` (або `nx update-self --check`, щоб лише перевірити).
Для `.deb`/`.pkg` став новий пакет.

## Команди

| Команда | Що робить |
|---|---|
| `nx файл.nx` | запустити файл |
| `nx ide` / `nx ide тека` | **Nx IDE** — середовище з блоками (як Scratch) і кодом, уроками й прикладами |
| `nx` | REPL — виконання рядок за рядком, `exit()` для виходу |
| `nx install owner/repo` | встановити бібліотеку з публічного GitHub-репозиторію |
| `nx install` | встановити все з `nx.json` у поточній папці |
| `nx uninstall name` | прибрати бібліотеку з `nx.json` і з `nx_modules/` |
| `nx update` / `nx update name` | оновити всі бібліотеки чи одну на поточний default branch |
| `nx format файл.nx` | форматувати файл |
| `nx lint файл.nx` | перевірити файл на типові помилки |
| `nx check файл.nx` | перевірити лише синтаксис (без виконання коду) |
| `nx update-self` | оновити nx (і IDE) до останнього релізу |
| `nx --version` | версія |

## Nx IDE — програмувати з нуля

```bash
nx ide
```

або ярлик **«Nx IDE»**. Відкриється [Nx IDE](https://github.com/Faneraiy14/NyxilumIDE) —
середовище, написане на самій NyxilumLang, однакове на Linux і Windows:

- **Блоки** (як Scratch): герой на сцені, малювання, списки, свої блоки; «Відкрити як код» і
  назад — «Відкрити як блоки».
- **Код** (як VS Code): підказки, F12 — до визначення, F2 — перейменувати всюди, розділений
  редактор, покроковий запуск (налагоджувач) і сцена для ігор прямо в IDE.
- **Уроки** з автоперевіркою й «Покажи мені», приклади, підказки до помилок простими словами.
- **Інструменти:** термінал, git (коміт, гілки, push), історія версій, розширення (вбудоване —
  Anylint; свої пишуться на NyxilumLang).
- **Вигляд:** теми (темна, світла, контрастна), згладжені шрифти, масштаб 100–200%.

Програми лежать у `~/NyxПрограми` (або `nx ide інша/тека`). Посібник — `ide/ПОСІБНИК.md`.

## Бібліотеки

Пакет — будь-який публічний GitHub-репозиторій із `main.nx` у корені:

```bash
nx install owner/repo
```

Тягне його в `nx_modules/<repo>/` і дописує залежність у `nx.json`
поруч із твоїм файлом — точним SHA коміта, а не назвою гілки, тож
повторний `nx install` завжди відтворює той самий байт-в-байт вміст,
навіть якщо гілку пакета пізніше оновили чи переписали. Підключення
без `.nx` і без шляху:

```nx
import "repo"

func main() {
    print(якась_функція_з_пакета())
}
```

Без аргументу `nx install` ставить усе, що вже перелічено в `nx.json`
поточної папки.

## Стандартна бібліотека (`lib/`)

В архіві поруч із `nx` лежить тека `lib/` — готові модулі на самій NyxilumLang:
`telegram.nx`, `discord.nx`, `http_client.nx`, `postgres.nx` і `mysql.nx`
(клієнти БД поверх голого TCP), `crypto.nx` (SHA-1/SHA-256/MD5/HMAC/PBKDF2),
`bytes.nx`, `datetime.nx`, `strings.nx`, `collections.nx`, `testing.nx`.
Підключаються за шляхом відносно твого файлу (скопіюй `lib/` поруч або
вкажи шлях до неї):

```nx
import "lib/postgres.nx"

func main() {
    var db = pgConnect("postgres://user:pass@localhost:5432/mydb")
    print(toJson(pgQuery(db, "SELECT now() AS t", [])))
    pgClose(db)
}
```

Можна й вибірково — `import "lib/postgres.nx" { pgConnect, pgQuery }`:
усе, від чого ці функції залежать, підтягнеться саме. Докладно — у `GUIDE.md`.

## Пісочниця для ненадійного коду

Якщо `.nx`-скрипт запускається від імені твого сервісу (напр. код,
згенерований ШІ) — `NX_SANDBOX=1 nx script.nx` обмежує файловий
доступ поточною директорією і повністю забороняє мережу та читання
змінних середовища. Вимкнено за замовчуванням.
